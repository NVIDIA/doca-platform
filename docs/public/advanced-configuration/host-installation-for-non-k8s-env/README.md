This section covers an **advanced configuration** of the [Host Trusted use case](../../user-guides/host-trusted/README.md) for environments where worker nodes are not part of a Kubernetes cluster.


Before proceeding with the advanced configuration, ensure you have installed DPF following the [Host Trusted Getting Started Guide](../../getting-started/dpf-host-trusted.md).

This documentation is organized into the following sections:

* [Host Installation for Non-Kubernetes Environments](non-k8s-host-installation.md) - Complete step-by-step installation guide for non-Kubernetes workers
* [Custom Provisioning with DMS CA](custom-provisioning-dms-ca.md) - Advanced configuration for custom certificate authority
