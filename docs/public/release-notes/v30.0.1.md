title: "DOCA Platform Framework v30.0.1"
---

This is a patch release on top of the 30.0.0 release of the DOCA Platform Framework (DPF).
It includes bug fixes and improvements to enhance the provisioning and orchestration of
NVIDIA BlueField DPUs in Kubernetes environments.

The [release notes for 30.0.0](./v30.0.0.md) still apply for this release and information
presented in this documentation is an amendment to the previous release notes.

### Revision History

| Date            | Description                                                            |
|-----------------|------------------------------------------------------------------------|
| November 2026   | General Availability (GA) release of DOCA Platform Framework v30.0.1   |

### Fixed Issues from Previous Release

* **Single-port BlueField-4 stuck in DPU Config**
    * Fixed the DPU agent uplink check so single-port BlueField-4 DPUs no longer remain stuck in
      `DPU Config` and can be provisioned to `Ready`.
